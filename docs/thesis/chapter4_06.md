# 4.6 与现有方法对比与本章小结

## 4.6.1 与现有方法的全面对比

为系统展示 K-HSTGAN 与现有代表性方法的差异，表 4-4 从五个维度给出详细对比。

**表 4-4** K-HSTGAN 与现有方法的对比
[三线表]

| 维度 | RE-GCN<br>[Li, SIGIR 2021] | GDN<br>[Deng, AAAI 2021] | xERTE<br>[Han, arXiv 2020] | 规则引擎<br>[3.5 节] | **K-HSTGAN** |
|------|-------------------------|-------------------------|-------------------------|------------------|--------------|
| **输入形式** | 文本三元组 $(s,p,o,t)$ | 多元传感器时间序列 | 文本三元组 $(s,p,o,t)$ | 场景层+行为层 实体/关系 | 属性图+张量序列 |
| **图构建方式** | 预构建（固定） | 结构学习（可训练） | 预构建（固定） | 无 | **STKG 显式构造（15 种关系先验）** |
| **空间关系编码** | 等权 GCN | 可结构学习 | 子图采样 | 无 | **关系感知 RGAT（可学习先验 $\gamma_k$）** |
| **时序建模** | GRU（全序列） | 滑动窗口预测 | 子图 GNN + 时间 Mask | 跨帧状态机 | **三层层次化 LSTM-Attention + 差分门控** |
| **知识注入** | 无 | 无 | 无 | 全部（符号） | **RSS 残差 + Rule Embedding + 弱监督** |
| **输出任务** | 链接预测 | 偏差评分 | 链接预测 | SafetyViolation | **多任务（4 头）** |
| **推理时解释** | 无 | 方差评分 | 注意力子图 | 证据链 | **注意力权重 + 证据链** |
| **规则缺失场景** | 可泛化 | 可泛化 | 可泛化 | 漏报 | **可泛化（知识注入辅助但不依赖）** |
| **训练窗口** | 全历史 | 滑动窗口 | 全历史 | 无训练 | **滑动窗口 T=30** |
| **样本需求** | 大量 | 大量 | 大量 | 零样本 | **小样本（利用规则弱监督初始）** |

K-HSTGAN 与 RE-GCN 在输入形式上存在本质差异：RE-GCN 消费离散三元组做 0-1 链路预测，K-HSTGAN 消费属性图（节点带连续张量，边带关系类型张量）做异常二分类与多任务分类。换言之，RE-GCN 解决的是"实体 A 在时刻 t+1 是否与实体 B 发生关系"，K-HSTGAN 解决的是"在帧 t，场景是否偏离正常行为模式"。两项任务形似而神异，不能直接比较 MRR/Hits@k 等链接预测指标。

与 GDN 的对比则凸显知识先验的优势：GDN 需要从从头学习传感器间的依赖关系（结构学习），在大规模图（传感器数 $> 100$）上训练不稳定；K-HSTGAN 复用 STKG 的场景关系（`in_lane`、`ahead_of`、`beside` 等）作为固定先验图结构，无需结构学习。

与纯规则引擎的对比展示 K-HSTGAN 对小样本异常（规则未覆盖类型）的泛化能力：规则引擎对已知规则（14 条交规 + 3 项 RSS）精准，但"偏离正常行为模式"类型的异常（如车辆行驶轨迹渐变的漂移、两车间距缓慢缩小）无对应规则检测时，规则引擎漏报率为 100%，K-HSTGAN 则可能从连续多帧的特征变化中学习到这类偏离。

## 4.6.2 本章小结

本章针对 STKG 在自动驾驶异常检测中的三方面挑战——场景关系重要性差异、时序差分稀疏性、规则知识注入途径——提出了**知识引导的层次化时空图注意力网络（K-HSTGAN）**。全章贡献如下：

**4.1 节**将异常检测任务形式化为 $f_\theta(G_{1..t}, \Delta g_{1..t}, \mathcal{K})$，给出对 STKG 三层结构的输入张量约定与 K-HSTGAN 四层架构全景；

**4.2 节**设计关系感知 GAT（RGAT），为 STKG 的 15 种场景关系分配独立注意力通道，并引入可学习关系先验 $\gamma_k$ 与动态门控 $g_k(\cdot)$ 做通道融合，解决了"15 种关系重要性差异无法表达"的问题；

**4.3 节**设计差分驱动的层次化 LSTM-Attention（DHLSTM-Attn），包含帧级差分门控（跳过 30%–50% 冗余帧）、行为级窗口注意力（聚焦 InteractionEvent 持续时间）、场景级 Transformer 自注意力（多帧自相似性编码）三层；

**4.4 节**设计三种知识注入策略：RSS 残差注入（$F$ → $F+5$ 特征层）、交规规则 Embedding（残差路径）、规则弱监督训练（$\gamma_3$ 递减控制）。三者互补地确保了规则知识的连续可微且不破坏模型泛化能力；

**4.5 节**设计多模态融合头与多任务训练策略：场景层 MeanPool + 行为层 InteractionEvent 聚合 + 规则层 SafetyViolation 拼接 $\to$ 4 头分类器；多任务损失（Focal Loss + CE + BCE）；三阶段训练（预训练→联合微调→主任务微调）+ 梯度裁剪 + EMA + 早停。

K-HSTGAN 以符号规则得到的 STKG 为输入，输出多任务异常预测与可解释注意力权重。它与 RE-GCN [Li et al., 2021]、GDN [Deng & Hooi, 2021] 及第 3 章规则引擎的对比，展示出在"知识先验利用 × 差分稀疏优化 × 多任务输出"三个维度上的差异化优势。下一章将在 K-HSTGAN 的基础上，进一步构建符号规则与神经网络的闭环融合框架 KS-NBCF，实现规则与 GNN 的双向增强。
