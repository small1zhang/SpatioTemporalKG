# 论文格式约定与排版指南

> 本文档约束 `docs/thesis/` 下所有章节文件的格式，遵循中国知网（CNKI）硕士学位论文提交格式要求。

---

## 1. 三线表标准

所有表格采用 **三线表** 格式，在最终 Word 排版阶段按以下规则转换。当前 Markdown 阶段用简化形式书写，标注 `[三线表]` 标识。

### 三线表样式规范

| 位置 | 线型 | 线宽 | 距内容距离 |
|------|------|------|-----------|
| 顶线 | 粗实线 | 1.5 pt | — |
| 表头线 | 细实线 | 0.75 pt | 表头行下方 |
| 底线 | 粗实线 | 1.5 pt | — |

**规则**：
- 无左右边框线
- 无竖线
- 无斜线
- 表头（首行）居中加粗，宋体小五号（9 pt）
- 表体数据宋体小五号（9 pt），数据列居中对齐，文字列左对齐
- 表注置于表下方，宋体六号（7.5 pt）
- 表序号按章编号（如"表 3-1"），位于表上方，黑体五号（10.5 pt），居中

### Markdown 阶段书写示例

```
**表 3-1** 实体类型与所属层级
[三线表]
| 实体类型 | 标签 | 所属层级 | 角色 |
|---------|------|---------|------|
| VEHICLE | Vehicle | 场景层 | 动态主体 |
| PEDESTRIAN | Pedestrian | 场景层 | 弱势主体 |
```

### 排版阶段操作

所有 `[三线表]` 标记的表格在 Word 中：
1. 选中整表 → "表格设计" → 取消所有边框
2. 设置顶线（1.5 pt）→ 表头下线（0.75 pt）→ 底线（1.5 pt）
3. 设置表头行粗体，表体数据对齐
4. 设置表前序号行

## 2. 字号与字体规范

| 元素 | 字体 | 字号 | 行距 | 对齐 |
|------|------|------|------|------|
| 一级标题（第 X 章）| 黑体 | 三号（16 pt）| 1.5 倍 | 居中 |
| 二级标题（X.X） | 黑体 | 四号（14 pt）| 1.5 倍 | 左对齐 |
| 三级标题（X.X.X）| 黑体 | 小四号（12 pt）| 1.5 倍 | 左对齐 |
| 正文 | 宋体 | 小四号（12 pt）| 1.5 倍 | 两端对齐 |
| 表序/图序 | 黑体 | 五号（10.5 pt）| 单倍 | 居中 |
| 表内容/图注 | 宋体 | 小五号（9 pt）| 单倍 | 居中/左对齐 |
| 公式编号 | 宋体 | 小四号（12 pt）| — | 右对齐 |
| 参考文献 | 宋体 | 五号（10.5 pt）| 1.25 倍 | — |

## 4. 公式规范

- 公式居中排版，编号右对齐，用圆括号括起，如（3-1）、（4-2）
- 正文中引用公式用"式 (3-1)"
- 长公式换行在运算符处，上一行末留运算符
- 变量用斜体，单位用正体

---

## 5. 本文档 Markdown 阶段的临时约定

- 三线表用 `[三线表]` 标记，Markdown 表格仅做内容占位
- 公式用 `\tag{3.1}` 标记编号（后续 Word 阶段转为（3-1）格式）
- 引文用 `[Author, Year]` 格式，后续统一按 GB/T 7714 展开
- 所有图用 ASCII 文本框图，最终 Word 阶段替换为 High-res 图片
