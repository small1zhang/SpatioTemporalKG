# 5.6 与现有融合方法对比与本章小结

## 5.6.1 与现有融合方法的对比

为系统展示 KS-NBCF 的差异化优势，表 5-4 从七个维度对比现有代表性融合方法。

**表 5-4** KS-NBCF 与现有融合方法对比
[三线表]

| 维度 | 简单 OR 投票 | 加权融合 | 单向规则注入 (Logic Tensor Networks) | 双向协同蒸馏 | **KS-NBCF** |
|------|------------|---------|----------------------------|-------------|-------------|
| 融合阶段 | 决策层 | 决策层 | 特征层 + 训练 | 训练 + 决策 | **特征 + 训练 + 决策（端到端）** |
| 规则可微性 | 不要求 | 不要求 | 要求（如规则损失 LTN）| 部分 | **不要求（D-S 处理决策融合）** |
| 双向信息流 | 否 | 否 | 单向（规则 → GNN）| 是（训练时） | **全程双向（训练+推理）** |
| 冲突建模 | 无 | 隐式（加权）| 无 | 无 | **显式（D-S 冲突系数 $K$）** |
| 不确定性表达 | 否 | 否 | 部分通过概率约束 | 否 | **是（quality function 含 $\Theta$ 焦元）** |
| 推理时可解释性 | 输出禁/投 | 输出加权 | 规则满足/不满足 | 蒸馏对齐图 | **STKG 证据链回溯短语** |
| 对未知异常泛化 | 取决于 GNN | GNN 主导 | GNN 主导 | GNN 主导 | **GNN 主导，规则弱监督** |

KS-NBCF 在七个维度中的差异均集中体现于"端到端融合 + 显式冲突建模 + KG 证据链可解释"三个层面：

- **端到端融合**：从特征（5.2 $\phi_{\text{feat}}$）→ 训练（5.3 $\phi_{\text{loop}}$）→ 决策（5.4 $\phi_{\text{fuse}}$）三阶段闭环，区别于仅决策层融合的传统方法；
- **显式冲突建模**：D-S 证据理论的冲突系数 $K$ 提供量化指标自动触发仲裁机制，避免传统加权法在 GNN 与规则高度冲突时坍缩为单一信号；
- **KG 证据链可解释**：以 STKG 的 `supportedByEvidence` 边为基础，在每帧的最终决策时输出可读短语级别的推理路径，可在下游 dashboard 可视化。

## 5.6.2 KS-NBCF 的适用与局限

### 适用场景

- **自动驾驶安全验证**：场景结构受 STKG 显式建模，规则与 GNN 互补性强；
- **小样本异常检测**：弱监督+规则先验可在标注样本少时仍保持训练稳定；
- **高可解释性需求**：监管审计、责任归因等需要可读推理路径的场景。

### 局限与展望

- **规则可微性不强**：D-S 融合在决策层处理两条流的矛盾，但规则 RSS 是闭式公式，无法可微反传 — 阶段 II 的反馈调整依赖区间搜索解决；
- **D-S 焦元固定为二分类**：异常 vs 正常的二分判定适合即时报警，但未来若要做多类别异常分类，需要扩展为多焦元的高复杂度 D-S 模型；
- **三阶段顺序耦合**：训练前→训练中→推理时三阶段时序不可逆，若需某阶段失败后向前回滚，目前未设计逆向恢复机制；
- **证据链回溯延迟**：在大型 STKG（节点>100 万级别）上 Cypher 查询可能超出实时性窗口，需要预先物化热路径查询。

上述局限部分由后续工作可缓解：未来可引入可微符号引擎（如 PyReason）将 RSS 公式转可微形式；多焦元 D-S 可使用 $\Theta = \{a_1, \dots, a_M\}$ 高维版本；证据链热路径可通过 Neo4j 物化视图加速。

## 5.6.3 本章小结

本章提出 **知识引导的符号-神经双向闭环融合框架（KS-NBCF）**，针对自动驾驶安全验证场景中规则引擎与图神经网络的对立统一关系，构建了三个互补子模块：

**5.1 节** 给出 KS-NBCF 的设计动机与总体架构，分析现有融合方法在自动驾驶场景中的三类冲突及需求；

**5.2 节** 设计 $\phi_{\text{feat}}$——特征层规则先验注入子模块，复用 4.4 节两种策略（RSS 残差拼接 + 交规 Embedding 残差），并将这一机制定位到符号-神经融合框架的特征层；

**5.3 节** 设计 $\phi_{\text{loop}}$——训练-推理三阶段双向闭环子模块，包含训练前弱监督标签生成（阶段 I）、训练中 GNN 反馈调整规则置信度（阶段 II）、推理时 GNN 注意力激活规则模板（阶段 III）三个前后衔接的机制，是 KS-NBCF 区别于单向注入的关键所在；

**5.4 节** 设计 $\phi_{\text{fuse}}$——D-S 证据理论融合与冲突消解子模块，给出规则与 GNN 的质量函数构造、Dempster 组合规则、冲突系数 $K$ 触发判定、KG 证据链回溯仲裁规则；针对三类典型冲突情形给出质量函数前后的演化分析；

**5.5 节** 给出端到端算法、复杂度分析与全部 11 个超参数的默认值清单；

**5.6 节**（本节）给出 KS-NBCF 与现有融合方法在七个维度上的对比，分析框架的适用场景与局限。

KS-NBCF 与第 3 章 STKG、第 4 章 K-HSTGAN 共同构成自动驾驶安全验证的"图谱+模型+融合"完整闭环。下一章将以 CARLA 仿真平台的实验数据，对三个层面的设计进行系统化性能评测与对比验证。
