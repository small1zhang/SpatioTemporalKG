# 三 Chunk 转入 Neo4j 可视化方案

## 目标
把 `viz_output/graph_0001_0_1999.json`、`graph_0002_2000_3999.json`、`graph_0003_4000_5999.json` 共 3 个 phase5 分片（总 13607 节点 / 386107 边）导入 Neo4j，用 Neo4j Browser 看。

## 决策点（已确认）
- **部署**：Docker 起新 Neo4j
- **节点粒度**：全局 MERGE，以 `entity_id` 为主键（Vehicle=486 在 3 shard 合并为 1 个节点）
- **前端**：Neo4j Browser (`http://localhost:7474`)
- **脚本位置**：复用 `stk/storage/` + 新建 `scripts/long_run/import_neo4j.py`

## 实施步骤

### 2) 修活 stk/storage/connector.py（伪连接 → 真驱动）
现有 `connector.py:8-36` 是桩代码 — `connect()` 只翻 bool，`run()` 永远返回 `[]`。改为真包装：
- `__init__` 接收 `uri/user/password/database`，`driver=neo4j.GraphDatabase.driver(uri, auth=(user, password))`
- `connect()` 检查 `driver.verify_connectivity()`
- `run(cypher, params)` 打开 `session(database=...)`，调用 `session.run(cypher, params).consume()`，返回 `data()`
- 新增 `run_batch(statements)` 用 `session.for_each(lambda tx,...)` 或 `UNWIND` 批量执行
保持 API 兼容（`ConnectionPool.acquire()` 调用面不变），但写一个真正的批量写函数。

### 3) 新增 stk/storage/importer.py（核心导入逻辑）
新文件，**消费 phase5 JSON dict 形态**（非 BaseEntity 形态），跟现有 `serializer.entity_merge_cypher` 类似但直接吃 dict。

布局：
```python
class GraphImporter:
    def __init__(self, conn: Neo4jConnection, batch_size=500, coalesce_frames=True)
    def ensure_schema(self)         # 跑 schema.get_schema_cypher() + 额外索引
    def import_shard(self, graph: dict)  # 单 shard 导入
        # 1) 写节点: UNWIND $batch AS row MERGE (n:Label {entity_id: row.id}) SET n += row.attrs, n.first_frame=min(...), n.last_frame=max(...)
        # 2) 写边: UNWIND $batch AS row MATCH (src) MATCH (dst) MERGE (src)-[r:TYPE]->(dst) SET r += row.attrs
        #    关键: 边的唯一键 = (src_id, dst_id, type, first_frame, last_frame)
    def import_dir(self, viz_output_dir)  # 遍历 graph_*.json + 加载 phase5_kg_summary.json
```

**节点 MERGE 规则**（全局合并）：
- `MERGE (n:Label {entity_id: $id})` 然后对 `first_frame`/`last_frame` 用 `min`/`max` 做时间区间合并
- 对 Vehicle/Pedestrian/Rule/ScenarioSnapshot: 一个 `entity_id` 全局只有 1 个节点，attrs 取最新 shard 的
- 对 `env_frame_*`、`int_*_frame_*`、`resp_sv_*_frame_*` 等 ID 含帧号 → 天然不会跨 shard 合并

**非 primitive attrs 处理**：
- `attrs.labels`、`attrs.fired_frames`、`attrs.frames`、`attrs.affected_lane_ids`、`attrs.reasons` 等 list → `json.dumps` 字符串存
- `attrs.attrs` (Maneuver/InteractionEvent 嵌套) → 平铺到 `attrs_attrs_*` 或存为 JSON string

**悬挂引用处理**（`definedBy`/`supportedByEvidence` 54553 条边指向不存在的 `sv_*_frame_*`/`scene_rel_*_frame_*`）：
- 默认 APOC `apoc.periodic.iterate` 可处理空 MATCH：边会被 SKIP（不报错但写不进去）。给出选项 `--create-dangling` 时给这些 src 创建 placeholder `:SafetyViolationInstance` 节点
- 默认 `--skip-dangling`，跳过 + 打印跳过条数

**边去重**：
- 用 `MERGE (src)-[r:TYPE {first_frame: $ff, last_frame: $lf}]->(dst)` 防止重复
- 同 src/dst/type 但不同 frame 区间会被合并；attrs 累积 SET（如 `fired_frames` 用 list 拼接 + distinct）

### 4) scripts/long_run/import_neo4j.py（CLI 入口）
```python
# 用法:
#   docker compose up -d  # 先
#   python -m scripts.long_run.import_neo4j --input viz_output/ --uri bolt://localhost:7687 --user neo4j --password stk123
import argparse, json, time
from stk.storage.connector import Neo4jConnection
from stk.storage.importer import GraphImporter

def main():
    args = parse_args()
    conn = Neo4jConnection(args.uri, args.user, args.password, args.database)
    conn.connect()
    importer = GraphImporter(conn, batch_size=args.batch_size, create_dangling=args.create_dangling)
    importer.ensure_schema()
    
    summary = json.load(open(f"{args.input}/phase5_kg_summary.json"))
    for shard in summary["shards"]:
        fname = f"graph_{shard['shard_idx']:04d}_{shard['frame_start']}_{shard['frame_end']}.json"
        graph = json.load(open(f"{args.input}/{fname}"))
        t0 = time.time()
        importer.import_shard(graph)
        print(f"shard {shard['shard_idx']}: {len(graph['nodes'])} nodes, {len(graph['edges'])} edges in {time.time()-t0:.1f}s")
    conn.close()

if __name__ == "__main__":
    main()
```

### 5) 索引/约束优化
`ensure_schema()` 执行（已存在 `get_schema_cypher()`）：
```cypher
CREATE CONSTRAINT vehicle_id_unique IF NOT EXISTS FOR (n:Vehicle) REQUIRE n.entity_id IS UNIQUE;
CREATE CONSTRAINT rule_id_unique IF NOT EXISTS FOR (n:Rule) REQUIRE n.entity_id IS UNIQUE;
CREATE INDEX frame_id_idx IF NOT EXISTS FOR (n:EnvironmentSnapshot) ON (n.frame_id);
CREATE INDEX sv_rule_idx IF NOT EXISTS FOR (n:SafetyViolation) ON (n.rule_code);
CREATE INDEX edge_frame_idx IF NOT EXISTS FOR ()-[r:in_lane]-() ON (r.first_frame, r.last_frame);
```

### 6) Neo4j Browser 几条验证 Cypher
导入完后给用户几条预置查询：
```cypher
// 自车 + 邻居
MATCH (n:Vehicle {entity_id: "486"})-[r]-(m) RETURN n, r, m LIMIT 100;

// 一段时间内违反的规则
MATCH (v:Vehicle)-[r:violates]->(sv:SafetyViolation)-[:definedBy]->(rule:Rule)
WHERE r.first_frame >= 0 AND r.last_frame <= 2000
RETURN v.entity_id, sv.rule_code, rule.rule_name, r.fired_frames LIMIT 50;

// ego 与其他车的空间关系
MATCH (e:Vehicle {is_ego: true})-[r:ahead_of|following|opposite_direction|overtaking|beside]->(o:Vehicle)
RETURN type(r), e.first_frame, r.first_frame, r.last_frame;
```

## 风险/约束
- `definedBy` 54553 条边中 43604 (80%) 指向不在节点集的 `scene_rel_*_frame_*` ID，默认跳过会少这 54553 个边；要保留就加 `--create-dangling`

- 386107 条边导入大约 2-5 分钟（Neo4j 单实例 + UNWIND 500/批）
